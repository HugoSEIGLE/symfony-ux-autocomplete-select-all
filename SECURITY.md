# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Do not open a public issue.

Use GitHub's **Report a vulnerability** form in the repository's Security tab:

<https://github.com/HugoSEIGLE/symfony-ux-autocomplete-select-all/security/advisories/new>

Include reproduction steps, affected versions and the expected impact. You
should receive an acknowledgement within 72 hours and a status update within
seven days. Please allow time for a coordinated release before public
disclosure.

Security fixes are released as patch versions whenever possible.
